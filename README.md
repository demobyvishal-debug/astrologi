# Astro Ankush Ji Website

Static single-page website (HTML/CSS/JS). Deploy on GitHub Pages.

## Before publishing
1. Replace `91XXXXXXXXXX` in index.html (2 places) with the real WhatsApp number (country code + number, no + or spaces).
2. Add photo: put `ankush.jpg` in `images/` and in index.html replace the `<svg>` inside `.portrait` with:
   `<img src="images/ankush.jpg" alt="Astro Ankush Ji">`

## Publish on GitHub Pages
1. Create a new GitHub repository and upload all files from this folder.
2. Go to Settings > Pages.
3. Source: Deploy from a branch > Branch: main, Folder: / (root) > Save.
4. After 1-2 minutes the site will be live at https://USERNAME.github.io/REPO-NAME/
